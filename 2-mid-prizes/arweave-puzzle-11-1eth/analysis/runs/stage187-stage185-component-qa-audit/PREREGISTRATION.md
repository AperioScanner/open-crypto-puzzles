# Stage187 — Stage185 composite-component QA implementation audit (preregistered)

Date: 2026-10-28 UTC. Branch: `research/arweave11-chatgpt`.

## Independently verifiable implementation/protocol defect
The Stage185 preregistration in `analysis/STAGE_QUEUE.md` explicitly required each of its **45 generated hull objects** to have at least **two nonwhite pixel clusters/contours at its nominal site**. Its implemented check in `tools/stage185_hull_curve_fragment_positive_audit.py` does NOT count connected components in the composite hull at any site. Instead it draws each nominal line onto a separate blank array, tests at least one nonempty component per *separate* stroke, and sets the misleading `>=two_nonempty_stroke_components_or_contours` flag from `sum(individually_detectable)>=2`. Distinct raster layers can merge into a single connected component when composited. This is a direct mismatch between the documented composite QA and the implemented check; it was not remedied by the archived Stage185 44/44 checks.

A **post-hoc exploratory reproduction before this preregistration** of the nine archived source-blind scene specifications found merged composite outlines in 12/45 site windows; these are **not new held-out data**. This stage is an integrity audit of Stage185 only, never an independent experiment on the source artwork.

Record per-site actual component count, the **original** metadata's `four_individually_rendered_hull_strokes`, and its `>=two_nonempty_stroke_components_or_contours` flag.
3. Fresh isolated component-counter sanity fixtures on a white 41x65 ROI (not original-image pixels): blank=0 components, one horizontal stroke=1, two separated horizontal strokes=2, and two strokes joined by a bridge=1. For all four fixtures count with the identical frozen threshold<245 and connectivity8, and check deterministic equality.

## Frozen decision and stopping criteria

Otherwise for each site compute discrepancy = archival metadata asserts `>=two...` but the composite ROI has <2 components. If there is **at least one** discrepancy, decision `STAGE185_COMPOSITE_COMPONENT_QA_MISMATCH_CONFIRMED`; otherwise `STAGE185_COMPOSITE_COMPONENT_QA_MATCHES`.
